# Contract Clause Sentry

> Clause-level contract risk, scanned in minutes

AI scanner that compares every clause to your playbook, flags deviations and proposes redlines before signature.

**Live:** https://ziontechgroup.com/contract-clause-sentry/  
**Network hub:** https://github.com/Zion-support/zion-app-network

## Features
- Clause extraction and classification across 60+ clause types
- Playbook deviation scoring with risk heat ratings
- Suggested redlines with fallback language
- Renewal-risk linkage to Contract Renewal Radar
